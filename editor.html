Cómo se publican los cambios

Este editor prepara un borrador en este navegador. No modifica la web pública. Cuando termines, descargá la web completa y reemplazá los archivos en tu repositorio de GitHub. Vercel publicará la actualización si el repositorio está conectado.

Los borradores se guardan en este dispositivo. Descargá una copia para conservarlos. Este editor no es un panel de acceso privado y no contiene credenciales.

Agregar contenido

Imágenes JPG, PNG o WebP (hasta 15 MB). Videos MP4 o WebM (hasta 40 MB). Para videos más grandes, usá YouTube o Vimeo.

YouTube, Vimeo o enlace directo HTTPS a MP4/WebM. Para imágenes usá un archivo.
